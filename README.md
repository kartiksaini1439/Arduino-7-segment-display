# Arduino 7-Segment Display

## About the Project
This is my first Arduino project, created to learn the basics of Embedded Systems and digital electronics.

## Project Status
Designed and tested using Tinkercad Circuits. The circuit has not yet been built physically.

## Tools Used
- Arduino Uno
- Tinkercad Circuits
- Arduino C/C++

## What I Learned
- Arduino programming basics
- Digital output pins
- 7-segment display operation
- Circuit simulation
